## 📌 Overview

This repository contains the source code for my personal **QA Portfolio Website**. It is designed to reflect high standards of software testing, displaying detailed bug reports, automation execution logs, interactive metric widgets, and end-to-end testing case studies.

### ✨ Key Features & Highlights

- ⚡ **Interactive QA Status Dashboard:** Displays real-time metrics, automation execution status (Playwright, Cypress, Selenium), and defect ratios.
- 📋 **Case Studies & Bug Reports:** Detailed walkthroughs of real-world testing scenarios, boundary value analysis, API test plans, and JIRA-style bug documentation.
- 🛠️ **Tech Stack & Skills Matrix:** Categorized overview of Manual, Automation, API (Postman/RestAssured), and Performance (JMeter) capabilities.
- 📱 **Fully Responsive & Cyber-Themed UI:** Sleek glassmorphism visual aesthetics optimized for desktop, tablet, and mobile browsers.
- 💬 **Interactive Modals & Filters:** Dynamic filtering for project case studies and interactive contact popups.
